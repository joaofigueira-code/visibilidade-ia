# Visibilidade em IA

Todos os dias às 08:00 UTC, o GitHub Actions faz 12 perguntas sobre plataformas de comércio eletrónico em Portugal ao Google (Gemini) e a um modelo da OpenAI (gpt-oss, pela Groq) e grava as respostas em `respostas/AAAA-MM-DD/`.

As respostas servem para medir se a Redicom é referida pelos motores de IA. Não há chaves nem dados de clientes neste repositório: as chaves estão nos Secrets.
